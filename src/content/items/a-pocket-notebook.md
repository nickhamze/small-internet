The best notebook for me is one I don't mind using badly. It needs to fit in a pocket, open easily, and survive an occasional shopping list beside a thought I might want to keep.

Fancy paper has its pleasures. So does being able to cross something out without feeling that I've spoiled a beautiful object.

## One place for the loose things

I write the date when I begin a page. After that, anything can go there: a word to look up, a rough shape, a project question, the name of a book someone mentioned. I don't sort these while I'm out. Sorting is a different job, and it can wait.

If an entry continues onto another page, I add the page number beside it. That's enough of a system to find my way back. The notebook doesn't need categories before it has something in it.

For [the field guide](/projects/pocket-field-guide/), I give a whole page to one observation. For errands, I use whatever space is left. The mix helps the notebook remain an everyday object instead of a special occasion.

## Empty it gently

Every so often, I read the recent pages and put a small mark beside anything I moved elsewhere. A link might join [the garden](/garden/). A question might become a note. Most things stay exactly where they are.

Moving everything would make the notebook feel like an inbox, and I have enough of those. I only carry something forward if I can see a reason to return to it.

## Before buying another

Try a folded sheet or the notebook already in a drawer. Carry it for a few days. Notice whether the size, binding, or page layout actually gets in your way.

Those small observations tell you more than a list of ideal features. A useful notebook is allowed to have bent corners, unfinished lists, and pages that don't become anything. It has done its job when the next thought has somewhere to land.
